二、必拿模块（按性价比排序）

① 编码规则 + 画波形（简答 5 分，5 份真题考 3 次）

- 曼彻斯特码（双相码）：中间必跳变；1 是高到低（下坡），0 是低到高（上坡），口诀"1 下坡，0 上坡"（教材 P229 口径，别记反）

- 差分曼彻斯特码（差分双相码）：中间必跳变，看开头：0 开头跳变、1 开头不跳变，口诀"0 动 1 静"

- CMI 码：0 固定编 01；1 交替编 11 和 00，口诀"0 是 01，1 翻跟头"（2025.10 官方答案原话）

- 真题原题：2024.4 差分码画 1011010010、2024.10 曼彻斯特画 1001011010、2025.10 CMI 画 0100110011；规则默写约 2 分、波形约 3 分，带尺子画两条电平线、按比特分格即可

② 子网划分五件套（综合大题，5 份考 2 次）

- 五步：网络地址（IP 与掩码逐位"与"）→ 掩码（由 / 位数换算，1 对应网络位）→ 广播地址（主机位全置 1，或下一子网地址减 1）→ 地址总数（2 的主机位数次方）→ 可分配范围（总数减 2，即网络地址 +1 到广播地址 −1）

- 例：203.123.1.135、掩码 255.255.255.192（即 /26，主机位 6 位）：网络地址 203.123.1.128，广播地址 203.123.1.191，总数 64，可分配 62 个，范围 203.123.1.129 ~ 203.123.1.190

- 附带：超网/CIDR 地址总数 = 2 的（32 − 前缀长度）次方（2024.4 单选考过 /22 共 1024 个地址）

③ CRC 模 2 除法（简答、单选、填空共出现 3 次）

- 三步：G(x) 写成二进制位串（位数减 1 = 冗余位 r）→ 数据后面补 r 个 0 → 与生成位串做模 2 除法（逐位异或、不借位），余数不足 r 位高位补 0，拼到数据尾部即编码结果；接收方再除一次，余数为 0 则无错

- 真题：2024.4 简答给 G(x)=x⁴+x²+x+1 对 100111011101 求校验位；步骤写全，结果算错也能拿大部分分

④ TCP 拥塞控制（简答 3 次 + 综合 1 次）

- 四算法：慢启动（cwnd 每 RTT 翻倍）、拥塞避免（每 RTT 加 1）、快重传（收到 3 个重复 ACK 立即重传）、快恢复

- 计时器超时：阈值 ssthresh = cwnd / 2，cwnd 重置为 1 MSS，重新慢启动

- 3 个重复 ACK：ssthresh = cwnd / 2，cwnd 直接设为 ssthresh，进拥塞避免（不回 1）

- 三次握手：SYN → SYN+ACK → ACK；四次挥手：FIN → ACK → FIN → ACK；确认号 = 期望收到的下一个序号（2023 年两份卷子单选都考过序号计算）

⑤ 差错控制四方式（简答考 3 次）

- 四方式：检错重发、前向纠错、反馈校验、检错丢弃；定义默写原话：通过差错编码技术实现对传输差错的检测，并基于某种机制进行差错纠正和处理

- 随机差错（随机噪声引起，孤立、稀疏、互不相关）vs 突发差错（冲击噪声引起，成串出现）；突发长度 = 第一个出错位到最后一个出错位之间的位数

⑥ 停-等 / GBN / SR（简答 1 次 + 综合 2 次）

- 停-等：发送、接收窗口都是 1，最简单、利用率最低；信道利用率 = 发送时延 /（发送时延 + RTT）

- GBN：累积确认，一个分组出错则后面已发的全部回退重传，适合低误码信道

- SR：逐个确认，只重传出错的那一个，接收方缓存乱序分组，适合高误码信道

- 一句话规律：窗口越大信道利用率越高，窗口足够大时接近 1

⑦ CSMA 三兄弟 + CSMA/CD（简答 2 次 + 计算 2 次）

- 非坚持（忙就随机等）、1-坚持（忙就盯着，空闲立刻发）、P-坚持（时隙制，空闲以概率 P 发）；统一口号"先听后说"

- CSMA/CD："边听边说"，靠信号强度检测冲突，只用于有线信道；冲突后用截断二进制指数退避

- 最短帧长公式：最短帧长 ≥ 往返传播时延 × 发送速率（保证发完前能检测到冲突）；2024.4 单选考最远距离、2024.10 填空考最小帧长，套的都是这一个公式

⑧ 时延三公式（综合 5 份考 4 次，计算第一优先级）

- 传输（发送）时延 = 分组长度 L / 链路速率 R

- 传播时延 = 距离 D / 传播速率 V（按题给值代入）

- 时延带宽积 = 传播时延 × 带宽（表示链路上能容纳的比特数）

- 吞吐量取全程最慢一段（瓶颈）的速率；做题先写公式再代数，结果错也有步骤分

⑨ 应用层速记（简答、填空高频区）

- Cookie：网站辨别用户身份、会话跟踪用的小型文本文件，存在用户本地；用途：统计访问人数、限制特定用户、记录偏好与登录信息、购物车（简答考 2 次）

- SMTP（TCP 25 端口）：握手、邮件传输、关闭三阶段；只能传 7 位 ASCII 内容，是"推"协议（简答考 1 次）

- POP3（110 端口）：授权、事务处理、更新三阶段；IMAP 的区别是可只读取邮件的一部分、服务器保留会话状态（出现 2 次）

- HTTP：非持久连接（一请求一连接）vs 持久连接（流水 / 非流水，2023.4 简答）；状态码 404 = 请求对象不存在

- DNS：递归查询（替你查到底）vs 迭代查询（告诉你下一步问谁）；分级：根（root）、顶级、权威、本地

- Socket 函数只记对应关系：TCP 服务端 socket → bind → listen → accept，客户端 connect，收发 recv / send；UDP 收发 recvfrom / sendto（综合题填函数名出现过）

⑩ IP 分片（简答 1 次 + 单选 1 次）

- 每片数据长度 ≤ MTU − 20（首部），且必须是 8 字节的整数倍（最后一片除外）

- 片偏移 = 该片数据起始字节数 / 8；MF=1 表示后面还有分片，MF=0 是最后一片；标识相同才属于同一原数据报

- 例：3400 字节数据报过 MTU=1500 的链路，分 3 片，数据 1480 / 1480 / 420，片偏移 0 / 185 / 370，MF 为 1 / 1 / 0

⑪ 路由三件套（单选年年考归属）

- 链路状态 LS（OSPF 用）：每结点洪泛链路状态，用 Dijkstra 算最短路，需要全局信息

- 距离向量 DV（RIP 用）：只和邻居交换距离表，基于 Bellman-Ford，收到通告后跳数 +1 比较取优

- OSPF 特点：链路状态、安全认证、分层（区域）、支持多条等价路径；BGP 是 AS 之间的外部协议，通告或撤销路由用 UPDATE 报文（BGP 简答 2024.10 考过）

⑫ 安全速记（以选择、填空为主）

- DES 密钥 56 位（名义 64 位含 8 位校验）

- 数字签名：发送方用私钥签名、接收方用公钥验证；配套单向散列算法用 SHA-1（2024.4 单选）；PGP 保护电子邮件安全，其分组密码是 IDEA（2025.10 单选）

- 报文认证 = 验"信"真不真（有没有被篡改），身份认证 = 验"人"是谁（见易错清单第 1 条）

- IDS 入侵检测：监视网络并产生警告；与防火墙的区别：防火墙按规则放行或拦截，IDS 负责发现并报警

- IPSec 核心两协议：AH + ESP；VPN 最核心的技术是隧道技术

- 凯撒密码：字母按密钥 k 循环移位，逐个字母算即可（2023.4 简答原题，k=3）

⑬ 无线速记（选择题区，记结论不抠原理）

- 802.11 共同特征：都用 CSMA/CA、帧格式相同、支持基础设施与自组织两种模式；"速率越高传得越远"是假话（见易错清单第 2 条）

- 无线不能边发边听，所以用 CSMA/CA（RTS/CTS + ACK），不用 CSMA/CD（2025.10 单选）

- 移动 IP：永久居所是家网，管事的是家代理；两个地址：永久地址 + 转交地址 COA；注册报文里的注册标识是 64 位（见易错清单第 8 条）

⑭ 附赠高频：交换机自学习转发表（综合 5 份考 3 次）

- 三步写满：按帧的源 MAC 自学习建表（记下入端口）→ 按目的 MAC 查表转发 → 查不到就泛洪（除入端口外全发）

- 广播帧永远泛洪；交换机只分割冲突域、不分割广播域；2025.10 综合 44 是 15 分大题，只考填两台交换机的 MAC 表

三、易错清单（考前速览，刷题实测 8 条）

1. 消息认证 vs 报文认证：题干"检验收到的消息是否是真实的"→选报文认证（教材术语，message authentication 的标准译法）。身份认证=验人，报文认证=验信。

2. IEEE 802.11 共同特征：都用 CSMA/CA、帧格式相同、支持基础设施+自组织模式。不属于共同特征的是"提高传输速率以传输更远距离"——速率越高距离越短，这句是假的。

3. 换位密码：属于传统加密（古典密码：换位、代换），不是对称密钥加密。

4. AES 特点：分组长度固定 128 位不可变，但密钥长度可选 128/192/256；"分组长度和密钥长度均不可变"不是 AES 特点。

5. 局域网最常见 UTP：5 类（教材口径）。

6. 传输层报文段：必须设置若干个字段用于携带信息（不是字节）。

7. 发送窗口内序号状态：只有"已用未被确认序号"和"可用但未使用序号"两种；"未用序号"不在发送窗口内。

8. 移动 IP 注册报文：携带 COA、HA、移动结点永久地址和注册标识；注册标识是 64 位，不是 32 位（"位数记错"型坑，同类：TCP 紧急指针 16 位、首部长度字段 4 位、DES 密钥 56 位）。
