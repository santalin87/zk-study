一、计算机网络概述与体系结构（选择/填空/名词解释高频区）

1. 计算机网络定义：互联的、自治的计算机的集合；最基本功能是数据通信，最突出的优点是资源共享。[B][C]

2. 逻辑组成：通信子网（网络核心：结点交换机、通信线路及设备，负责高效可靠的数据通信）+ 资源子网（网络边缘：主机、终端、软件，负责数据处理）。[A][B]

3. 网络分类：按覆盖范围 LAN / MAN / WAN；按交换方式 电路交换网 / 报文交换网 / 分组交换网；按拓扑 星型 / 树型 / 总线型 / 环型 / 网状型。[B]

4. 协议三要素：语法、语义、时序（"时序"指执行各种操作的条件与顺序关系）。[B] [真题实测] 2023.10 简答 36 直接考"简述三要素及其定义的内容"，必背。

10. 时延计算是综合题必考：时延 = 发送时延 + 传播时延 + 排队时延 + 处理时延；吞吐量取瓶颈链路速率；时延带宽积 = 传播时延 × 带宽。[C] [真题实测] 4/5 份综合题考时延/吞吐量/信道利用率计算（2023.4-42、2023.10-42、2024.10-42、2025.10-42）；2025.10 单选 4 考"文件传送的吞吐量"（取三段链路最小速率）。

5. OSI 七层（自下而上）：物理层、数据链路层、网络层、传输层、会话层、表示层、应用层；TCP/IP 四层：网络接口层（数据链路层）、网际层、运输层、应用层。各层传输单元：物理层比特、数据链路层帧、网络层分组/数据报、传输层报文段。[B]

6. 电路交换 vs 分组交换（简答高频）：电路交换需建立连接、资源独占、时延小实时性强、信道利用率低；分组交换存储转发、无需预先建连、线路利用率高、可能失序/丢失/重复、只适用于数字信号。[B]

7. 性能指标：速率（bps）、带宽（Hz / 最高数据率）、时延 = 发送时延 + 传播时延 + 排队时延 + 处理时延、时延带宽积、吞吐量、丢包率。[C]

8. 接入方式：DSL、电缆（HFC）、FTTH、拨号、以太网、WiFi；物理媒体：双绞铜线、同轴电缆、光纤、无线信道。[B]

9. 网络体系结构 = 各层 + 各层协议 + 层间接口的集合；服务通过服务访问点（SAP）向紧邻上层提供。[C]

二、物理层

1. 传输介质特性比较：双绞线（100m，易受干扰）/ 同轴电缆 / 光纤（速率高、损耗小、抗电磁干扰强、误码率约 1e-9~1e-10、保密性好）/ 无线。[B][C]

2. 奈奎斯特定理（无噪声）：Rmax = 2·f（bps）；香农定理（有噪声）：Rmax = B·log₂(1+S/N)。[C] [真题实测] 香农公式计算考了 2 次（2023.10 单选 17：信噪比 30dB、八进制、8KHz；2025.10 单选 23：16KHz、30dB）。

5. 编码规则 + 画波形图是简答固定题型：曼彻斯特码（双相码）、差分曼彻斯特码（差分双相码）、CMI 码的编码规则必须会默写 + 给定比特串画波形。[C] [真题实测] 5 份考了 3 次：2024.4-41（差分双相码，画 1011010010 波形）、2024.10-41（双相码/曼彻斯特码，画 1001011010 波形）、2025.10-41（CMI 码，画 0100110011 波形）。这是 04741 最有规律的送分简答，务必拿下。

6. 二进制数字调制：2ASK、2FSK、2PSK、2DPSK 的中文名称及综合性能比较。[C] [真题实测] 2023.10 简答 40（四种中文名+综合性能）；2024.10 单选 24：频带利用率最低的是 2ASK；2024.4 单选 24：误码率最高的是 2ASK。

3. 多路复用：频分 FDM / 时分 TDM（含同步 STDM 与统计/异步 ATDM）/ 波分 WDM（光纤）/ 码分 CDM；对应 MAC 协议 FDMA / TDMA / WDMA / CDMA。[A][B]

4. 物理层设备：中继器、集线器工作在物理层（集线器下连的仍是一个冲突域）。[B][C]

7. [真题实测] 2025.10 官方答案：填空 33 答案 9600bps、填空 34 答案 1110（两题题干未见，多为速率/二进制编码类小题，待核实）。

三、数据链路层与局域网（2018 版·第五章）[A]

> 本节全部出自与指定教材版本直接对应的 [A]，是本清单可靠度最高的一章，优先背。

1. 数据链路层功能：组帧、链路接入（点对点链路 / 广播链路）、可靠传递、差错控制；传输的数据单元称为帧；典型硬件是网卡（NIC）（实现数据链路层+物理层功能）。[A]

2. 差错控制四种机制：检错重发、前向纠错（适用于单工链路或实时性要求高的应用）、回退校验、检错丢弃。[A] [真题实测] 2024.4 简答 38（差错产生原因 + 差错控制概念 + 四种基本控制方式）；2025.10 简答 40（差错控制概念、差错两种类型及特点）；填空常考（2023.4-29、2023.10-29）。

2b. 随机差错 vs 突发差错：随机差错孤立出现、突发差错成串出现；突发长度指突发差错中第一个出错位到最后一个出错位之间的位数（含正确位）。[C] [真题实测] 2024.10 简答 38。 2c. 停-等协议：发送窗口 = 1、接收窗口 = 1，可靠传输最简单的形式，信道利用率最低。[B] [真题实测] 2024.10 简答 36（主要特点及基本工作过程）；2023.10 综合 42（停等协议信道利用率计算）。

3. 汉明距离：两等长码字对应位不同的位数为 dc；编码集的汉明距离 ds = 任意两码字间最小值。检错：ds = r+1 可检测 r 位差错；纠错：ds = 2r+1 可纠正 r 位差错。[A]

4. 典型差错编码：奇偶校验码（1 位冗余，开销最小，检错率不高，用于低速串行链路）、汉明码（线性分组码，可纠 1 位错，需满足 2^r ≥ k+r+1）、CRC 循环冗余码（多项式编码；生成多项式 G(X) 最高位与最低位系数必须为 1；编码三步：后补 r 个 0 → 模 2 除法求余数 R → 相减得编码帧；广泛用于以太网、802.11、PPP）。[A] [真题实测] CRC 编码计算是简答常客：2024.4-40（G(x)=x⁴+x²+x+1，对 100111011101 求 CRC 校验位并写出编码结果，要求写计算过程）；2024.10 单选 19（G(x)=x⁴+x+1，对 100111011101 做 CRC 编码）；2025.10 填空 34（G(x)=x⁴+x+1，对 1101011011 求 CRC 冗余位）。模 2 除法必须练熟。

5. MAC 协议三类：信道划分（多路复用实现）、随机接入（ALOHA、CSMA、CSMA/CD）、受控接入（集中式轮询 / 分散式令牌）。根本任务是解决信道共享问题。[A]

6. ALOHA 吞吐量（计算题备选）：纯 ALOHA：S = G·e^(-2G)，G=0.5 时 S 最高 18.4%；时隙 ALOHA：S = G·e^(-G)，G=1 时 S 最高 36.8%。[A]

7. CSMA 三种：非坚持（忙则随机等待，冲突少但信道空闲多）、1-坚持（忙则持续监听，空闲立即发，冲突多）、P-坚持（时隙信道，以概率 P 发送）。概括"先听后说"。[A]

8. CSMA/CD（"先听后说，边听边说"）：冲突检测靠信号强度，只适用于有线信道；最小帧长与距离关系：Lmin/R ≥ 2·Dmax/v（往返时延内必须能检测到冲突）；冲突后用截断二进制指数退避算法重发。[A]

9. 以太网帧结构：目的地址 6B + 源地址 6B + 类型 2B + 数据 46~1500B + CRC 4B；类型 0x0800 表示封装 IP 数据报。[A]

10. MAC 地址：6 字节十六进制；全球唯一、扁平结构（不随位置改变）；广播地址 FF-FF-FF-FF-FF-FF。[A]

11. ARP：根据 IP 地址获取 MAC 地址；ARP 请求用广播帧发送、响应单播返回；ARP 表自动建立、即插即用。[A][B]

12. 交换机原理：自学习（按源 MAC 建表）+ 转发/过滤（按目的 MAC 查表）；查不到则泛洪（flood）；广播/组播帧向所有端口转发。[A][B] [真题实测] 综合题最爱考：2023.10-44（B 发帧给 A、A 回复 B，写交换机和主机工作过程 + 补全交换表）、2024.4-42（13 分，交换机+三台主机，写 A→B、C→B 的转发过程 + 写新增表项）、2025.10-44（15 分，Switch1/Switch2 的 MAC 地址表填写）。自学习建表 + 查表转发 + 泛洪三步必须会写。

13. 冲突域 vs 广播域：交换机分割冲突域、不能分割广播域；路由器可分割广播域。[A][B]

14. VLAN：基于交换机的逻辑分割广播域，抑制广播风暴；划分方法：基于端口 / 基于 MAC 地址 / 基于上层协议。[A][B]

15. PPP 与 HDLC：点对点链路不存在媒体共享问题，不需要 MAC 协议；PPP 三功能：成帧、LCP 链路控制协议、NCP 网络控制协议（PPP 只检错不纠错）；透明传输：PPP 用字节填充（转义字节 0x7D）、HDLC 用位填充（5 个连续 1 插 0）。[A] [真题实测] 2023.10 填空 33（HDLC 为保证透明传输用了____方法）；2024.4 单选 20（HDLC 控制字段首位为 0 表示该帧为____）。

16. CSMA/CD 工作原理（简答高频）："先听后发、边发边听"；冲突检测；二进制指数退避；最小帧长。[A] [真题实测] 2023.10 简答 39；2024.4 单选 22（CSMA/CD 最远距离计算）；2024.10 填空 33（CSMA/CD 最小帧长计算）。

17. P-坚持 CSMA 基本原理：时隙信道，监听到空闲以概率 P 发送、以概率 1-P 推迟到下一时隙。[C] [真题实测] 2025.10 简答 39。

18. ARP 过程（综合题）：ARP 请求广播、响应单播；跨网段时主机先把 IP 分组发给默认网关。[A][B] [真题实测] 2024.10 综合 43（13 分，给拓扑图 + ARP 表，写 ARP 查询分组的源/目的 IP 与 MAC、链路层帧目的地址、路由器处理、响应分组、更新 ARP 表项）。

16. 交换机 vs 路由器（简答高频）：交换机工作在数据链路层、按 MAC 地址转发、只分割冲突域；路由器工作在网络层、按 IP 地址（网络 ID）选路、可分割广播域、隔离不需要的通信量。[B]

四、网络层

1. 虚电路网络 vs 数据报网络：虚电路在网络层提供面向连接服务（路径+VC 号+沿途转发表项）；数据报网络提供无连接服务（每个分组独立选路，可能失序/丢失/重复）。[B]

2. 路由器工作原理：工作在 OSI 第三层；按目的 IP 查转发表；TTL 减 1 并重算校验和；加上下一跳 MAC 后从输出端口转发（排队等待）。[B]

3. IPv4 数据报首部字段：版本、首部长度、服务类型、总长度、标识/标志/片偏移（与分片有关）、TTL（防无限循环）、协议、首部校验和、源/目的 IP 地址。[B]

4. 子网划分计算（计算题最高频）：子网数 = 2^x（x 为子网位），每子网主机数 = 2^y − 2；block size = 256 − 掩码十进制数；广播地址 = 下一子网号 − 1。[B]

5. CIDR 与路由聚合：超网划分，最长前缀匹配。[C] [真题实测] 2024.4 单选 15：子网 195.125.0.0/24 为 C 类地址网络，超网 195.125.0.0/22 中 IP 地址总数和包括的 C 类地址网络个数（1024 和 4）。超网包含的子网数 = 2^(被借位差)，会算。

6. ICMP：网络层差错/控制报文；ping 用回送请求/应答测连通性，tracert 利用 TTL 超时测路径。[B]

7. DHCP：动态分配 IP；四阶段：发现 → 提供 → 选择 → 确认。[B]

8. NAT：私网地址 ↔ 公网地址转换，缓解 IPv4 地址不足。[B]

9. 路由算法：距离向量（RIP，基于 Bellman-Ford，定期交换路由表）vs 链路状态（OSPF，Dijkstra，洪泛链路状态）；BGP 为外部网关/策略路由协议。[B][C] [真题实测] 内部网关协议辨析是选择高频：2024.4 单选 18（基于链路状态路由选择算法的内部网关协议是 OSPF）、2024.10 单选 18（基于距离向量路由选择算法的内部网关协议是 RIP）、2023.4 单选 9（Internet 标准的外部网关协议是 BGP）；2024.10 简答 40（BGP 实现的功能及 BGP 对 AS 的作用）；RIP 路由表更新是综合题：2023.10-43（12 分，给 R6 路由表 + R4 的 RIP 通告，写更新后路由表）；Dijkstra 最短路径是综合题：2025.10-43（8 分，给拓扑图填结点 D 的路由表）。

10. IPv6：地址 128 位、基本首部固定 40 字节。[B] [真题实测] 2024.4 单选 17、2024.10 单选 17 都考"IPv6 基本首部长度为固定的 40 字节"；2025.10 单选 17 考 IPv6 地址书写正确性判断。

11. 路由器利用目的 IP 查路由表：最长前缀匹配；TTL 减 1。[B] [真题实测] 2024.4 简答 37（简述路由器利用 IP 数据报的目的 IP 地址检索匹配路由表的过程）；2025.10 填空 32 答案：默认路由器（主机默认网关）。

12. IP 分片：MTU 限制；标识/标志/片偏移。[B] [真题实测] 2023.10 简答 38（MTU=1500 字节链路转发 3800 字节 IP 数据报的分片过程）；2025.10 单选 14（总长度 5800B、MTU 1400B 的分片数）。

13. 移动 IP：归属代理、外部代理、COA 转交地址。[B] [真题实测] 2023.4 简答 40（移动 IP 结点通过外部代理完成向归属代理注册 COA 的步骤）。

五、传输层

1. TCP vs UDP（简答高频）：TCP 面向连接、可靠（确认/重传/流量与拥塞控制），适合大数据量；UDP 无连接、不可靠、速度快，适合实时应用（DNS、视频）。[B]

2. 套接字：UDP 套接字 = 二元组（目的 IP + 目的端口）；TCP 套接字 = 四元组（源 IP、源端口、目的 IP、目的端口）。[B]

3. TCP 报文首部：源/目的端口号、序号、确认号、接收窗口、首部长度、6 个标志位、校验和；功能：连接管理、流量控制、可靠传输、拥塞控制。[B]

4. 可靠传输机制：回退 N 步（GBN）与选择重传（SR）是流水线差错恢复的两种基本方法。[B] [真题实测] GBN/SR 是综合题重灾区：2023.4-43（13 分，GBN 累积 ACK 确认，问发送/接收窗口、收到 ACK1/ACK0/ACK2 后的操作、是否重传）；2024.4-44（11 分，SR 滑动窗口，问收到 ACK1/ACK0/ACK2 后的操作、为何收到两个 2 号分组）；2025.10 单选 11（GBN 超时重传题目）、单选 18（停-等和滑动窗口实现的是检错重发）。

5. 流量控制与拥塞控制：滑动窗口 + 累积确认；慢开始 / 拥塞避免、门限 ssthresh、超时与 3 个重复 ACK 的不同处理。[B][C] [真题实测] 2024.10 简答 37（流量控制和拥塞控制的区别）；2025.10 简答 38（"拥塞"概念、直接后果及 TCP 拥塞控制机制）；拥塞控制计算是综合题：2024.10-44（12 分，MSS=1KB、计时器超时/3 重复 ACK 后的拥塞窗口阈值与窗口大小、慢启动进入拥塞避免的 RTT 数）；2025.10-42(4)（慢启动每 RTT 翻倍）；2025.10 填空 29（拥塞避免阶段 cwnd=32MSS 超时后阈值调整）。

6. 三次握手建连、四次挥手释放。[B][C] [真题实测] 5 份真题均未要求画三次握手时序图，不押画图；但 TCP 序号/确认号计算是选择高频：2023.4 单选 24（两段 400B+600B、首序号 800，求确认序号）、2023.10 单选 24（300B+400B+200B、第 3 段序号 800，第 2 段丢失求确认序号）。

7. UDP 首部 8 字节固定；TCP 首部最大 60 字节（首部长度字段×4）。[B] [真题实测] 2023.10 单选 7（UDP 数据报首部长度）、2023.4 单选 23（TCP 报文段最大首部长度）、2024.10 单选 11（首部长度字段值为 10，求最大首部长度和选项字段）。

7. 熟知端口号：FTP 21、Telnet 23、SMTP 25、DNS 53、HTTP 80、POP3 110。[B]

六、应用层

1. DNS：主机名 → IP 地址；运行在 UDP 53 上；递归查询（代为查到底）vs 迭代查询（告诉你下一步找谁）；服务器分级：根 / 顶级 / 权威 / 本地。[B][C] [真题实测] 2025.10 填空 30 答案：root（DNS 根域名服务器）。

2. HTTP：超文本传输协议；非持久连接（每请求一建连）vs 持久连接（流水/非流水）；请求方法 GET / HEAD / POST；状态码 2xx 成功 / 3xx 重定向 / 4xx 客户端错 / 5xx 服务器错；Cookie 弥补无状态性。[B][C] [真题实测] 2023.4 简答 37（HTTP/1.1 持久连接的主要约束与规则）、简答 38（Cookie 概念及安全问题）；2025.10 简答 36（Web 网站利用 Cookie 用户跟踪的最常见用途）；2024.4 填空 28（"客户端请求对象在服务器上不存在"时状态码为 404）；2025.10 填空 28 答案：Web 服务器。

3. 电子邮件：发送 SMTP（TCP 25），读取 POP3（110）/ IMAP / HTTP；MIME 让 SMTP 传非 7 位 ASCII 内容。[B][C] [真题实测] 2023.10 简答 37（SMTP 发送邮件的过程）；2023.4 单选 17（允许用户代理只读取邮件部分内容的邮件读取协议是 IMAP）；2025.10 填空 35（同题）。

4. FTP：21 号端口，控制连接 + 数据连接双连接，双向传文件。[B]

5. C/S vs P2P：C/S 中客户间不直接通信、服务器有固定 IP；P2P 对等实体直接通信、无专用服务器。[B]

七、网络安全与网络管理

1. 防火墙：软硬件结合体，隔离内网与 Internet，按规则允许/阻止分组通过。[B]

2. IDS：入侵检测系统，监视网络/系统运行状况，发现攻击企图与行为。[B]

3. IPSec：IP 层开放安全架构，用加密保障 IP 通信的机密性与安全。[B]

4. 网络管理五大功能：性能管理、故障管理、配置管理、计费（账户）管理、安全管理。[B]

5. 加密与认证：凯撒密码（单表代换，密钥 k 移位）；PGP 用的分组密码是 IDEA；单向散列典型算法 SHA-1 / MD5；MAC 报文认证码 = H(m+s) 类构造。[B][C] [真题实测] 2023.4 简答 41（凯撒密码优缺点 + 密钥 k=3 对"This is an easy problem"加密求密文）；2025.10 单选 25（PGP 分组密码是 IDEA）；2024.4 单选 25（数字签名的单向散列算法是 SHA-1）；2023.10 单选 25（报文 m 和认证密钥 s 得 MAC 是 H(m,s)）。结论：加密考概念 + 凯撒密码手工计算，不考大题证明。

6. 网络准入控制：对接入网络的用户/设备进行身份认证与合规性检查，不合规者隔离或拒绝接入。[C] [真题实测] 2025.10 填空 31 答案：准入控制。

八、无线网络

1. 802.11 / WiFi：无线局域网标准；SSID 为服务集标识，用于划分需独立身份验证的子网络。[B] [真题实测] 2024.10 单选 23（信号传播距离最远、穿透能力较好、速率 11Mbit/s 的无线局域网标准是 IEEE802.11b）。

2. CSMA/CA：无线信道不能边发边听，用 RTS/CTS + ACK 回避冲突（与 CSMA/CD 的"冲突检测"对比是简答备选）。[B] [真题实测] 2025.10 单选 24（IEEE802.11 的 MAC 协议采用 CSMA/CA）。

九、真题实测·综合题题型清单（35 分，3 小题，必拿下计算）

按 5 份真题出现频率排序：

1. 时延/吞吐量/信道利用率计算（4/5 份）：发送时延 = 分组长度/带宽；传播时延 = 距离/传播速率；吞吐量 = min(各段速率)；停等协议利用率 = 发送时延/(发送时延+RTT)；GBN/SR 利用率按窗口折算。[真题实测]

2. GBN / SR 滑动窗口协议分析（2/5 份）：Ws/Wr 取值；收到乱序 ACK 后的动作（GBN 累积确认、SR 独立确认）；重传判断。[真题实测]

3. 子网划分计算（2/5 份）：子网数、每子网主机数、子网地址、广播地址、可用 IP 范围。[真题实测]

4. 交换机自学习与转发表（3/5 份）：按源 MAC 建表、按目的 MAC 转发/泛洪；补全交换表。[真题实测]

5. ARP 跨网段过程（1/5 份）：请求广播、响应单播、经默认网关；ARP 表项更新。[真题实测]

6. TCP 拥塞控制计算（2/5 份）：超时 → ssthresh=cwnd/2、cwnd=1MSS 进慢启动；3 重复 ACK → ssthresh=cwnd/2、cwnd=ssthresh 进拥塞避免；慢启动每 RTT 翻倍。[真题实测]

7. RIP 路由表更新（1/5 份）：收邻居通告 → 跳数+1 → 下一跳改为通告者 → 取更优。[真题实测]

8. Dijkstra 最短路径（1/5 份）：给拓扑图填路由表。[真题实测]

冲刺建议（真题校准版）

1. 题型结构已定：单选 25 分 + 填空 10 分 + 简答 30 分 + 综合 35 分。综合题 35 分全是计算/分析，是拉开差距的关键；简答 30 分高度可押。

2. 综合题突击顺序（按出现频率）：时延/吞吐量/信道利用率计算 → GBN/SR 窗口分析 → 子网划分 → 交换机转发表 → TCP 拥塞控制 → ARP → RIP/Dijkstra。每类找一道真题亲手算一遍。

3. 简答题必背：编码规则+画波形（曼彻斯特/差分曼彻斯特/CMI，三选一必考）、CRC 编码计算、差错控制四方式、流量控制 vs 拥塞控制、CSMA/CD、停-等协议、P-坚持 CSMA、VLAN、BGP、协议三要素、SMTP 过程、Cookie。
