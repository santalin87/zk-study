二、必拿模块（按性价比排序）

① 第二章·中国共产党舆论观（新大纲新增核心章，2026.4 一章出 13 分）

- 演进六阶段按顺序背：作为向导（建党初期）→ 作为斗争 → 作为宣传 → 作为导向 → 作为引导 → 作为治国理政（新时代成熟完善，判断题原题）

- 多选题"四个作为"（斗争 / 宣传 / 导向 / 引导）2026.4 是全选，见到这类题先按全选处理再核对

- 简答原题"舆论观演进中的启示"六点，官方原答：与时俱进、人民中心、科学管理（舆情监测预警引导机制）、法治保障、媒介融合、全球化视野，一点一句展开即满 10 分的量

- 新时代七个创新点知道名词即可（新概念、新定位、新表述、新论断、新擘画、新部署、新要求），不展开背

② 第十二章·舆论产业链 + 舆论监测（论述 20 分原题 + 单选原题）

- 论述框架四层背熟：上游数据采集与监测（监测软件平台商、爬虫与数据采集商、社交媒体 API 接口商、新闻网站论坛短视频等数据源）→ 中游数据分析与加工（舆情分析机构、情感分析与文本挖掘商、可视化报告机构、人工研判与专家解读）→ 下游应用与服务交付（政府、企业、媒体、公关公司、金融机构）→ 支撑层（云计算大数据基础设施、AI 与 NLP 技术、学术研究机构、行业协会与标准组织）

- 市场五特征附在框架尾巴上：技术驱动、平台集中度高、政策敏感性强、需求多样化、数据源依赖性强

- 舆论监测的基本方法：定向采集 + 非定向采集（2026.4 单选原题）；监测报告的通用结构知道标题、概况、研判、建议四块即可

③ 名词解释四件套（2026.4 原题，20 分里最稳的一块）

- 媒体审判：新闻媒体在司法程序尚未终结前，通过倾向性报道或评论对案件预先定性、定罪，影响公众判断乃至司法公正的现象

- 民粹主义：强调平民群众利益和意志、反对精英集团和既有政治体制的政治思潮或社会运动，以"人民"为话语核心，反建制、直接民主、情绪化表达

- 人肉搜索引擎：利用互联网平台、通过网民人工参与和信息协作，对特定人物、事件进行信息挖掘和身份追踪的网络信息搜索方式

- 信度：测量工具的可靠性、稳定性和一致性程度；信度高意味着多次测量结果一致性高

- 背法：四条全部按官方参考答案逐字背，名解是"定义写对就给分"的题，不自己改写

④ 第九章·舆论的数量与质量（单选、多选、名解多点开花）

- 回音壁效应：使群内同质性和群际异质性双向增强（2026.4 单选原题）；同组概念还有信念回响、过滤泡、社群茧房，别混（见易混区第 7 条）

- 决定舆论质量的四要素（2026.4 多选全选）：意见发表的平台、群体利益相关性、意见发表的自由程度、意见领袖的介入时机

- 网络舆论定量判断四指标（2026.4 多选全选）：传播扩散度、民众关注度、内容敏感度、态度倾向性

- 民粹主义的四种表现、五大特点、双刃剑效应只记关键词；网络民族主义记三阶段和与民粹主义"合谋"（细见易混区第 6 条）

⑤ 第一章·舆论的定义（单选送分最集中）

- 死记三连：卢梭（法国）1744 年首次提出"公共舆论"的现代意义；"舆论"一词最早可追溯到范晔《后汉书》；梁启超的舆论主张是"通民隐、达民情"

- 数字与术语：两高司法解释——诽谤信息被点击、浏览 5000 次以上或被转发 500 次以上认定情节严重；"两微一端" = 微信、微博、客户端

- 舆论概念的五种误区各记一句：新闻≠舆论、传媒≠舆论、意识形态≠舆论、公众≠舆论、个人感觉≠舆论

- 判断原题："多数人"还是"少数人"都不能构成判断舆论主体的必要元素（对）；民意可以因认知变化而改变（"不可以随意改变"是错）

⑥ 第十、十一章·舆论测量（跨卷高频，新旧两套卷都爱考）

- 内容分析法：方法特征是客观、系统、定量（2026.4 多选原题，只缺一个"简单"是干扰项）；实施六步（2025.4 简答原题）：定问题与假设、界定总体与抽样、建类目体系、定编码规则并培训编码员、信度检验、统计分析

- 抽样只记归属：PPS 抽样属于概率抽样（2026.4 单选原题），入户调查、人口调查一般用概率抽样；非概率抽样四种是偶遇、判断、定额、滚雪球

- 旧卷遗产（福建旧卷三卷连考、新卷没考但成本极低，一并背）：测量层次"类序距比"加例子——定类（性别）、定序（文化程度）、定距（温度、智商，无绝对零点）、定比（身高）；利克特量表属于总加量表；问卷设计三步骤（探索性工作、设计问卷初稿、试用和修改）；调查报告三部分（导言、主体、讨论）

⑦ 第八章·舆论的传播周期（阶段类题目成串出现）

- 网络舆论六阶段：潜伏 → 爆发 → 蔓延 → 反复 → 缓解 → 长尾；长尾期的原因是事件已成为"社会集体记忆"（2026.4 单选原题）

- 舆论发展生命周期四段（2026.4 多选全选）：生成、发展、高潮、消亡——注意和六阶段是两套话，别答串

- 两种导入型：网络首发型与传统媒体首发型，阶段表现不一样（2026.4 判断原题，"一样"是错的）

- 社交媒体时代新六阶段知道链条即可：爆料 → 热点化 → 新闻化 → 集中化 → 段子化 → 标签化

⑧ 第五章·舆论的主体（多选三要素类集中区）

- 意见领袖三要素（2026.4 多选原题，拉扎斯菲尔德）：人格属性、能力、社会声望（"资本"是干扰项）

- 态度形成三阶段（2026.4 多选原题）：依从、同化、内化（"异化"是干扰项）

- 网民特征记关键词：三低人群为主、九大心理特征、群体极化、网络暴力；网络水军的演变三阶段和网络推手概念作简答、名解备选，记定义不背长文

⑨ 论述框架库（20 分只背三个框架，任中一个写满都够 9 分）

- 框架一：舆论产业链（见模块②，四层加五特征，2026.4 原题）

- 框架二：中共舆论观演进与启示（见模块①，六阶段加六点启示，可同时顶简答）

- 框架三：舆论形成的六个阶段（旧卷以论述、简答、简答三卷连考）：潜舆论酝酿 → 话题公开化 → 意见分化交锋 → 舆论高涨 → 舆论成熟（分布呈正态分布）→ 衰减与反馈；每阶段配 2-3 个特点展开

- 注意区分：框架三是舆论"形成"的通用过程，模块⑦的六阶段是网络舆论"传播周期"，两套阶段名称不要互相套用

⑩ 第十三章·研判、引导与控制（简答原题区）

- 舆论分析的基本原则（2026.4 简答原题）六条：客观性、系统性、动态性、分层分析、定性与定量结合、价值中立，一条一句展开

- 舆论调控的理论前提就是调控的必要性和可能性（旧卷三卷连考，新卷降格出选择、判断也照样能答）：必要性记舆论两面性、群体心理非理性、舆论与事实可能脱节、维护公共利益四点；可能性记规律可把握、手段可调控、公众可沟通、制度渠道畅通四点

- 引导控制的手段记五个名词：事实信息、传播通路与节点、舆论客体、意见信息、情绪

⑪ 第四章·舆论的本体（形态分类题）

- 存在形态三分类：潜舆论、显舆论、行为舆论（大纲名解示例就是"行为舆论"）；信息形态三分类：信息形态、意见形态、艺术形态，两组别串（见易混区第 2 条）

- 艺术形态多选（2026.4 全选）：音乐《小苹果》、电影《哪吒2》、舞蹈《江南 style》、网游《黑神话·悟空》——这类"全是例子"的题按全选处理

- 三种异变记定义：网络谣言（七种议题、后真相、社交货币化）、网络流行语、网络表情包（"帝吧出征"）；旧卷名解标准答法（舆论、网络舆论、突发事件）在背诵清单第三节，一并扫一遍

三、易混 / 易错区（考前速览，条条有真题出处）

1. 信度 vs 效度：信度 = 可靠性、稳定性、一致性（2026.4 名解原题只考信度）；效度 = 测得准不准、是否测到了想测的东西。问卷试用阶段两个都要验，别互换。

2. 两组"三形态"别串：存在形态 = 潜舆论、显舆论、行为舆论；信息形态 = 信息形态、意见形态、艺术形态。问"存在"答前一组，问"信息"答后一组。

3. 测量层次类序距比：定类（性别）、定序（文化程度）、定距（温度、智商，无绝对零点）、定比（身高，有绝对零点）；定序测量一定建立在定类测量基础之上（旧卷填空原话）。

4. 概率抽样 vs 非概率抽样：概率 = 简单随机、分层、整群、多段、PPS；非概率 = 偶遇、判断、定额、滚雪球。入户调查、人口调查用概率抽样（2026.4 单选原题）。

5. 网络首发型 vs 传统媒体首发型：首发媒体属性和导入方式不同，阶段表现也不一样；判断题里说"阶段表现一样"就是错（2026.4 判断原题）。

6. 民粹主义 vs 网络民族主义：民粹主义对内，反精英、反建制，以"人民"为话语核心；民族主义对外，涉国家利益、与民粹主义"合谋"，代表形象"小粉红"。两者都有双刃剑效应，别把对象答反。

7. 回音壁 vs 信念回响 vs 过滤泡：回音壁 = 社群茧房，群内同质、群际异质双向增强（2026.4 单选原题）；信念回响 = 信念被证伪后仍持续影响判断（2025.4 名解原题）；过滤泡 = 算法按个人偏好推信息形成的信息茧房。

8. 舆论 vs 民意 vs 舆情：民意是个人意见的集合，可以随认知变化而改变（判断题"不可以随意改变"是错）；舆情是舆论的发展形态；个人感觉不等于舆论（第一章五种误区）。

9. 媒体审判 vs 舆论监督：媒体审判是贬义——司法未终结就预先定性定罪、越界干预司法；舆论监督是正当监督。名解题写"媒体审判"时必须带批评口径，别写成媒体的正当职能。

10. 作为导向 vs 作为引导别颠倒：演进顺序是向导（建党初期）→ 斗争 → 宣传 → 导向 → 引导 → 治国理政；"作为治国理政的舆论是新时代中共舆论观的成熟完善"（2026.4 判断原题，对）。
