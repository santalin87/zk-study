## 方程式与练习题验算结论

关键方程式逐条核对了原子守恒与电荷守恒，全部配平无误：

- 胶体制备：FeCl₃ + 3H₂O ＝(煮沸) Fe(OH)₃（胶体）+ 3HCl。
- 电离方程式：H₂SO₄ ＝ 2H⁺ + SO₄²⁻、Ba(OH)₂ ＝ Ba²⁺ + 2OH⁻、Al₂(SO₄)₃ ＝ 2Al³⁺ + 3SO₄²⁻、NaHSO₄ ＝ Na⁺ + H⁺ + SO₄²⁻（水溶液）、NaHCO₃ ＝ Na⁺ + HCO₃⁻、CH₃COOH ⇌ CH₃COO⁻ + H⁺、H₂CO₃ 分步电离，两边电荷均守恒。
- 离子方程式：Ba²⁺ + SO₄²⁻ ＝ BaSO₄↓、CaCO₃ + 2H⁺ ＝ Ca²⁺ + H₂O + CO₂↑、Cu²⁺ + SO₄²⁻ + Ba²⁺ + 2OH⁻ ＝ Cu(OH)₂↓ + BaSO₄↓、Ca²⁺ + 2HCO₃⁻ + 2OH⁻ ＝ CaCO₃↓ + CO₃²⁻ + 2H₂O（石灰水少量），拆写规则与守恒逐条核过，含与量有关的写法区分（石灰水少量/过量）。
- 氧化还原：Fe₂O₃ + 3CO ＝(高温) 2Fe + 3CO₂（Fe 降 6、 C 升 6）、MnO₂ + 4HCl（浓）＝(加热) MnCl₂ + Cl₂↑ + 2H₂O（转移 2e⁻，只有 2 个 Cl 变价）、2Al + 6HCl ＝ 2AlCl₃ + 3H₂↑（转移 6e⁻）、3Cu + 8HNO₃（稀）＝ 3Cu(NO₃)₂ + 2NO↑ + 4H₂O（Cu 升 6、N 降 6，氧化剂与还原剂之比 2∶3）、Cl₂ + 2NaOH ＝ NaCl + NaClO + H₂O（歧化）、SO₂ + 2H₂S ＝ 3S↓ + 2H₂O（归中），化合价升降与电子转移数逐一核对。
- 消毒剂：Ca(ClO)₂ + CO₂ + H₂O ＝ CaCO₃↓ + 2HClO、2HClO ＝(光照) 2HCl + O₂↑、ClO⁻ + Cl⁻ + 2H⁺ ＝ Cl₂↑ + H₂O（电荷左 −1−1+2＝0，守恒）。
