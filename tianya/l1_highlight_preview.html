集合的概念

数学 · 必修第一册 · 第一章 1.1 节 · 视频内容速览（高亮样板）

先看这三句

把一些确定的、互不相同的对象看成一个整体，就是集合；整体里的每个对象叫元素。

常用数集的记号要记牢：N 自然数（从 0 开始）、N* 或 N+ 正整数、Z 整数、Q 有理数、R 实数。

同一个式子，代表元素不同，集合完全不同。

这一课讲 1.1 集合的概念与表示，是整个高中数学的第一课。老师开场就交代：集合这套语言是给后面学函数打底的，概念必须非常熟。

先是定义：把一些确定的、互不相同的对象看成一个整体，就是集合；整体里的每个对象叫元素。集合用大写字母表示，元素用小写字母。还特别讲了空集：描述完全明确、但一个元素都找不到的集合，比如平方小于 0 的实数组成的集合。

然后是元素和集合的关系：属于和不属于。老师特别强调，这个符号只能连元素和集合，不能拿来连两个集合。

常用数集的记号要记牢：N 自然数（从 0 开始）、N* 或 N+ 正整数、Z 整数、Q 有理数、R 实数。老师记有理数有个取巧的办法：实数里只有三类是无理数——π、e、开方开不尽的数（比如根号 2），剩下的都是有理数。

接着讲元素的三个性质。确定性：「个子高的同学」「课本里的难题」标准不客观，成不了集合；「世界最高的七座山峰」有客观标准，能成集合，跟你知不知道是哪七座没关系。互异性：同一个元素只写一次，这是考得最多的性质——例题里 x+2、x² 和 1 是三个元素，就必须两两不相等，推出 x 不能取 1、-1 和 2。无序性：谁写在前面都一样，集合只看谁在里面。

表示方法两种：列举法把元素一个个写出来；描述法写成 {x | 条件}，看的时候先看清代表元素是谁、范围是什么、条件是什么。老师反复提醒两个坑：一是代表元素换成什么字母都不影响集合本身；二是装点的集合写出来还得是点，比如两条直线的交点要写成 (-1, -2) 这一个点，不能拆成两个数。同一个式子 y=x²+1，代表元素是 x，得到的是 R；是 y，得到的是大于等于 1 的数；是点，得到的是抛物线上的点集——代表元素不同，集合完全不同。

最后一块是区间表示法，初中没学过、高中必须会：能取到的端点用中括号（闭），取不到用小括号（开），无穷大那头永远用小括号。以后求解集要用集合或区间来写，只写 x 大于几、小于几，在高中不算集合。

易错提醒：空集不是 {0}；写描述法别把代表元素的范围丢掉；点集别把点拆开写。

解题技巧（这一课能直接拿分的手法）

技巧1 · 判集合看标准，不看你知不知道：问“能不能组成集合”，只看标准客不客观。“个子高的同学”“课本里的难题”标准不客观，不行；“世界最高的七座山峰”有客观标准，行，跟你能不能说出是哪七座没关系。

技巧2 · 含参数先列禁区（互异性）：集合里几个元素带同一个参数，先让它们两两不相等，把参数不能取的值全排掉。比如元素是 x+2、x² 和 1，就必须 x≠1、-1、2；最后把剩下的候选值代回去验一遍有没有撞车。

技巧3 · 读描述法先圈代表元素：先问一句“这集合装的是数还是点”。同一个 y=x²+1，代表元素是 x，集合是 R；是 y，是 [1, +∞)；是点 (x, y)，是抛物线上的点集——公式没变，集合全变。

技巧4 · 区间端点：取得到用中括号，取不到用小括号：无穷大那头永远小括号。最后写答案用集合或区间，只写“x 大于几”在高中不算答完。

高考真题（出处已核，答案已验算）

2024 · 北京卷 · 第 1 题：已知 M = {x | -3 < x < 1}，N = {x | -1 ≤ x < 4}，则 M ∪ N =（　）
A. {x | -1 ≤ x < 1}　B. {x | x > -3}　C. {x | -3 < x < 4}　D. {x | x < 4}
答案 C。用技巧 4：并集是把两段在数轴上连起来取总范围，左端 -3 取不到、右端 4 取不到，所以是 (-3, 4)。

2021 · 新高考 I 卷 · 第 1 题（福建就考这个卷）：设 A = {x | -2 < x < 4}，B = {2, 3, 4, 5}，则 A ∩ B =（　）
A. {2}　B. {2, 3}　C. {3, 4}　D. {2, 3, 4}
答案 B。用技巧 3 的读法：一边是列举、一边是描述，就把 B 的元素逐个拿去 A 的条件里验，4 不满足 x < 4，先划掉。
